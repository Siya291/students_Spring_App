# MIE_Students

A Spring Boot application for managing Students records with PostgreSQL and JPA. This project demonstrates a simple REST API for creating and retrieving students information.

## Overview

This application is built using:

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok

It provides a basic backend service for storing students profiles and retrieving them via REST endpoints.
